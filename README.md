# E-Commerce Shopping Cart System 🛒

An object-oriented shopping cart system developed in Java. This project serves as a practical implementation of core Object-Oriented Programming (OOP) principles to simulate a real-world e-commerce checkout process.

## Features
* **OOP Architecture:** Built using Inheritance, Polymorphism, Abstraction, and Interfaces.
* **Product Management:** Handles multiple product types, including `DigitalProduct`, `PhysicalProduct`, and `ExpirableProduct`.
* **Smart Checkout Logic:** 
  * Validates customer balance and calculates dynamic shipping fees based on product weight.
  * Enforces strict expiration date checks before processing physical goods.
  * Manages stock availability and out-of-stock scenarios automatically.
* **Robust Testing:** Includes test cases for happy paths, insufficient balances, expired items, and empty cart edge cases.

## Technologies Used
* **Language:** Java (JDK)
